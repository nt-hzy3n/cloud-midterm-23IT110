## Local Setup

1. Install dependencies:
```bash
npm install
```

2. Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```

3. Configure environment variables in `.env`.

4. Run the application:
```bash
npm start
```

5. Development mode:
```bash
npm run dev
```
